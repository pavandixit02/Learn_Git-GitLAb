1. What is SSH?

SSH (Secure Shell) is a cryptographic network protocol that provides secure communication between two systems over an untrusted network.

GitLab mein SSH ka use primarily Git operations ko authenticate karne ke liye kiya ja sakta hai, jaise:

  • Git clone
  • Git fetch
  • Git pull
  • Git push
Simple Definition: SSH ek secure authentication method hai jisse tum apne computer ko GitLab account ke saath authenticate kar sakte ho without entering your GitLab password for every Git operation.

SSH ka Real-Life Example

Imagine karo tumhare paas ek house hai.

Private Key = Tumhari secret key
Public Key = Lock ke corresponding public information
GitLab = Secure server

Private key tumhare computer par rehti hai. Public key GitLab account mein add hoti hai. GitLab tumhari private key ko kabhi receive nahi karta.

2. HTTPS vs SSH

Git repository ke saath communicate karne ke liye GitLab mein HTTPS aur SSH dono approaches use ki ja sakti hain.

Feature HTTPS SSH
Authentication HTTPS credentials/token based authentication SSH key based authentication
URL Example https://gitlab.com/user/project.git git@gitlab.com:user/project.git
SSH Key Required No Yes
Repeated Credential Entry Depends on credential configuration Normally not required after setup
Common DevOps Usage Common Very common
Important: SSH authentication does not mean that GitLab receives or stores your private key. Only the public key should be added to GitLab.

3. Step 1 — Check Existing SSH Key

New SSH key generate karne se pehle check karo ki tumhare system mein already SSH key available hai ya nahi.

Linux / Ubuntu

ls -la ~/.ssh

Common SSH Key Files

  • id_ed25519
  • id_ed25519.pub
  • id_rsa
  • id_rsa.pub
Important:

id_ed25519 or id_rsa private key ho sakti hai.
id_ed25519.pub or id_rsa.pub public key hoti hai.

Private key ko GitLab, GitHub, WhatsApp, email ya kisi person ke saath share mat karo.

Check Public Key

cat ~/.ssh/id_ed25519.pub

Agar file exist nahi karti, tab new key generate kar sakte ho.

4. Step 2 — Generate SSH Key

Modern systems par Ed25519 key commonly recommended option hai because it provides strong security with a compact key size.

Recommended Command

ssh-keygen -t ed25519 -C "your-email@example.com"

Command Breakdown

Part Meaning
ssh-keygen SSH key generation utility
-t Key type specify karta hai
ed25519 Ed25519 key algorithm
-C Comment add karta hai
Email Key ko identify karne ke liye comment

Command Run Karne ke Baad

Terminal tumse file location pooch sakta hai:

Enter file in which to save the key

Default location accept karne ke liye Enter press kar sakte ho.

Passphrase

SSH key generation ke time passphrase set karna security improve kar sakta hai.

Recommended: Agar practical environment hai, to private key ko passphrase ke saath protect karna useful hai.

Generated Files

~/.ssh/id_ed25519 ~/.ssh/id_ed25519.pub

Yahan:

  • id_ed25519 = Private Key
  • id_ed25519.pub = Public Key

5. Step 3 — Start SSH Agent

SSH agent private keys ko memory mein manage karne mein help karta hai, especially jab key passphrase protected ho.

Start SSH Agent

eval "$(ssh-agent -s)"

Add Private Key to Agent

ssh-add ~/.ssh/id_ed25519

Check Loaded Keys

ssh-add -l
Remember:
ssh-agent mein private key add karna GitLab ko private key upload karna nahi hai.

Private key tumhare local system par hi rehti hai.

6. Step 4 — Copy Public SSH Key

Ab humein sirf public key copy karni hai.

Linux / Ubuntu

cat ~/.ssh/id_ed25519.pub

Output kuch is type ka hoga: 

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIxxxxxxxxxxxxxxxxxxxxxxxx your-email@example.com
DO NOT COPY THIS:
~/.ssh/id_ed25519

Ye private key hai.

Public Key Copy Karna

cat ~/.ssh/id_ed25519.pub

Complete single line ko copy karo.

7. Step 5 — Add SSH Key to GitLab

GitLab Account mein Login Karo

  1. GitLab open karo.
  2. Apne account mein login karo.
  3. Profile/settings area open karo.
  4. SSH Keys section find karo.

SSH Keys Page

GitLab mein SSH Keys settings page par:

  1. Public SSH key paste karo.
  2. Key ke liye descriptive title enter karo.
  3. Available usage/type options ko check karo.
  4. Key add/save karo.
Example Title:
Ubuntu Laptop

Ya:
Dell Precision Ubuntu

Title ka purpose hai ki future mein tum identify kar sako ki kaunsi machine ki SSH key GitLab account mein registered hai.

8. Step 6 — Test GitLab SSH Connection

Key add karne ke baad connection test karna important hai.

Command

ssh -T git@gitlab.com

First connection par SSH host authenticity confirmation prompt aa sakta hai.

GitLab ke current official documentation ke according expected successful authentication message account authentication confirm karta hai.

Success ka meaning:

Tumhara local SSH client GitLab ke SSH server se authenticate kar pa raha hai.

Verbose Mode

Agar connection fail ho raha hai, detailed debugging information ke liye:

ssh -Tvvv git@gitlab.com

9. Step 7 — GitLab Repository Clone Using SSH

GitLab repository page par jao aur Clone → SSH option select karo.

Example SSH URL

git@gitlab.com:username/project-name.git

Clone Command

git clone git@gitlab.com:username/project-name.git

Enter Project Directory

cd project-name

Check Remote

git remote -v

Output mein SSH URL visible hona chahiye.

10. Step 8 — Push Code Using SSH

Commit

Push

SSH configured hone ke baad Git operations SSH authentication ke through GitLab ke saath communicate kar sakte hain.

12. Common SSH Errors & Solutions

Error 1 — Permission denied (publickey)

Permission denied (publickey).

Possible Reasons

  • SSH key GitLab account mein add nahi hai.
  • Wrong public key add ki gayi hai.
  • SSH agent mein key loaded nahi hai.
  • Wrong private key use ho rahi hai.
  • SSH configuration incorrect hai.

Check Agent

ssh-add -l

Add Key

ssh-add ~/.ssh/id_ed25519

Test Again

ssh -T git@gitlab.com

Error 2 — Repository uses HTTPS

Check:

git remote -v

Agar remote kuch aisa hai: 

https://gitlab.com/username/project.git

aur tum SSH use karna chahte ho, remote URL change kar sakte ho.

Change HTTPS to SSH

git remote set-url origin git@gitlab.com:username/project.git

Verify

git remote -v

Error 3 — SSH Key File Not Found

ls -la ~/.ssh

Agar expected key nahi hai to correct key path identify karo ya new SSH key generate karo.

13. SSH Config File

Agar multiple SSH keys ya multiple Git hosting accounts use kar rahe ho, to SSH config useful ho sakti hai.

Config File

~/.ssh/config

Example

Host gitlab.com
    HostName gitlab.com
    User git
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes
Note: Multiple accounts/keys configure karte waqt host aliases aur identity selection ko carefully configure karna chahiye.

14. RSA vs Ed25519

Feature Ed25519 RSA
Modern Choice Yes Older but widely supported
Key Size Compact Usually much larger
Performance Efficient Generally heavier
Command ssh-keygen -t ed25519 ssh-keygen -t rsa -b 4096
Learning Recommendation: New Linux/DevOps setup mein Ed25519 ko first option ke roop mein samajhna useful hai. Legacy compatibility ke case mein RSA ki zarurat ho sakti hai.

15. SSH Security Best Practices

  • Private key kabhi share mat karo.
  • Public key aur private key ka difference samjho.
  • Private key ko unnecessary locations par copy mat karo.
  • Passphrase protected key use karna consider karo.
  • Public key ko sirf trusted services/accounts mein add karo.
  • Lost/stolen machine ki SSH key ko GitLab se revoke/remove karo.
  • Multiple machines ke liye separate keys maintain karna useful ho sakta hai.
NEVER SHARE: 
-----BEGIN OPENSSH PRIVATE KEY-----
...
-----END OPENSSH PRIVATE KEY-----
Agar private key expose ho jaaye, us key ko compromised maan kar GitLab account se remove/rotate karna chahiye.
